# Customer Churn Prediction

## Project Overview

Customer churn is one of the most important business challenges for subscription-based companies. Acquiring new customers is significantly more expensive than retaining existing ones, making churn prediction a critical business problem.

This project develops an end-to-end machine learning solution to identify customers who are likely to leave the company. The project combines business understanding, exploratory data analysis, feature engineering, predictive modeling, and business recommendations.

---

## Business Problem

Can we predict which customers are likely to churn before they leave the company?

By identifying high-risk customers early, businesses can take proactive retention actions and reduce revenue loss.

---

## Objectives

- Understand customer churn behavior.
- Identify the major factors influencing churn.
- Build machine learning models to predict customer churn.
- Evaluate model performance using appropriate classification metrics.
- Generate actionable business recommendations.

---

## Dataset

**IBM Telco Customer Churn Dataset**

The dataset contains customer demographics, subscription details, billing information, and churn status.

Target Variable:

- Churn
